### ⚡ OrderFlow

> Meu laboratório para sistemas distribuídos.

Projeto criado para experimentar decisões arquiteturais fora das limitações de um CRUD tradicional.

```text
Order
   │
   ├──▶ Inventory
   │
   ├──▶ Payment
   │
   └──▶ Notification

        ↕ events

   Kafka / RabbitMQ
```

Aqui exploro conceitos como:

`Microservices` · `Kafka` · `RabbitMQ` · `Spring Cloud Gateway` · `Resilience4j` · `Docker`

O objetivo não é apenas "usar microsserviços", mas entender **quando a complexidade distribuída faz sentido e quais problemas ela cria**.
